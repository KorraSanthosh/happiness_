GlucoTwin AI uses only anonymised research data and clearly labelled synthetic data. This file records where each dataset comes from, how it is used, what is (and is not) in this repository, and its licence.

## What is in this repository

| Path | Content | Origin |
|---|---|---|
| `backend/data/twin_v7/` | Dashboard demo pack: 30 people, up to 14 days each, resampled to a 5-minute grid | Shanghai T2DM / T1DM, AZT1D, T1D-UOM, HUPA-UCM only (CC BY 4.0); attribution in `ATTRIBUTION.md`. No BrisT1D, no OhioT1DM. |

## What is deliberately not in this repository

- Raw datasets (`external_data/`, `brist1d_raw/`, `ohiot1dm_raw/`, zip files).
- Experiment frames, held-out prediction files and full research models under `models/combined_*/` (`*.parquet`, `*.joblib`): they contain dataset-derived rows, including OhioT1DM.

To regenerate them: `backend/scripts/download_open_data.py` downloads the CC BY datasets; BrisT1D requires a Kaggle account; OhioT1DM requires signing its data-use agreement. Then follow "Model training and evaluation" in the README.

## Population limitation

No openly licensed CGM dataset from **Indian** people with Type 2 diabetes was found. The Type 2 data comes from China (Shanghai); performance on Indian patients is unknown and requires a prospective validation study.

## User uploads

Files uploaded through the dashboard's *My data* page are processed by the local backend, kept in memory only, never written to disk, and deleted on request or when the server stops.
